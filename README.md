# 🎬 Netflix Clone (Static Website)

A fully responsive **Netflix Clone** built using modern frontend technologies.  
This project replicates the UI design and layout of Netflix’s homepage using only frontend development skills.

> ⚠️ This is a static project created for educational and practice purposes only.

---

## 📌 Project Overview

This Netflix Clone mimics the look and feel of the original Netflix landing page.  
It focuses on layout structure, responsive design, and clean UI styling.

### ✨ Key Highlights:
- 🎥 Hero banner section
- 📺 Movie / TV show rows
- 🔥 Trending section layout
- 📱 Fully responsive design
- 🎨 Modern Netflix-style UI

---

## 🛠️ Technologies Used

- HTML5  
- CSS3   

---

## 🚀 Features

- ✅ Netflix-style navigation bar  
- ✅ Background hero section with overlay  
- ✅ Content rows with posters  
- ✅ Responsive design (Mobile, Tablet, Desktop)  
- ✅ Footer section similar to Netflix
